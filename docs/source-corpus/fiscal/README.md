# Sources Fiscales

Ajouter ici uniquement des sources fiscales validees ou publiques.

Exemples attendus:

- extraits CGI Burkina Faso;
- doctrine fiscale;
- referentiel de taux ou seuils;
- note fiscale validee.

Ne pas inventer de contenu fiscal. Les fichiers squelettes servent seulement a preparer le remplissage.
