## Blocs

### Bareme mensuel

- `block_reference`: `article 112`
- `block_type`: `article`
- `theme`: `bareme IUTS`

```text
Art.112.- L'impot unique sur les traitements et salaires est calcule et
retenu mensuellement par l'employeur pour le compte du Tresor public.

Les taux applicables au revenu mensuel imposable sont fixes comme suit,
pour chaque tranche de revenu : 0 a 30.000 francs CFA : 0 % ; 30.100 a
50.000 : 12,10 % ; 50.100 a 80.000 : 13,90 % ; 80.100 a 120.000 : 15,70 % ;
120.100 a 170.000 : 18,40 % ; 170.100 a 250.000 : 21,70 % ; 250.100 et
au-dessus : 25 %.
```

### Charges de famille

- `block_reference`: `article 113 paragraphe 1`
- `block_type`: `article`
- `theme`: `reduction charges de famille`

```text
Art.113.- 1) Sur le montant de l'impot ainsi calcule, il est pratique une
reduction d'impot pour charges de famille comme suit : 1 charge : 8 % ;
2 charges : 10 % ; 3 charges : 12 % ; 4 charges : 14 %.
```

### Declaration et versement

- `block_reference`: `article 116 paragraphe 1`
- `block_type`: `article`
- `theme`: `echeance IUTS`

```text
Art.116.- 1) Les retenues afferentes aux paiements effectues au titre d'un
mois determine, doivent etre declarees et versees dans les dix (10)
premiers jours du mois suivant, a la caisse du Receveur des impots de
rattachement de la personne qui les a operees.
```
